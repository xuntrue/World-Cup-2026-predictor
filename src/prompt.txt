## Analysis code conventions (analyse_data.py, finished)
- A thin orchestrator calls one `_print_*` helper per printed section, each with `plot: bool`.
- Shared helpers: section, _subsection, save_fig, counts_and_shares, _bin_start, _bin_label, _BIN_TITLES, _apply_bin_ticks, pair_key, tournament_group, prepare.
- Tables print counts and shares to 2 decimal places. Plots use a manually defined colour palette, major and minor gridlines, and set_axisbelow(True).
- bin_size (1, 5, 10 years) is a parameter. I like comment/uncomment toggles written as `if True: ... else: ...` blocks.
- Sections cover: missing values and types, duplicates, former names, matches over time, tournaments by group, score distributions, teams, shootouts versus results, goalscorers.
- I planned to write up findings in a Jupyter notebook (notebooks/data_findings.ipynb) that calls these functions. I have used LaTeX before.

## Findings so far
- Goals per match fell from about 4 in the 1920s to about 2.5 in the 1980s, then settled around 2.7 to 2.8 since 2000.
- Outcomes by venue, non-neutral: away 9,596, draw 8,308, home 18,443. Neutral: away 4,364, draw 2,925, home 5,769. Home wins fall about 6.6 points at neutral venues, draws barely change, and the "home" label still wins more often at neutral venues (44% versus 33%).
- A chi-square test and Poisson checks were written but I haven't pasted their output yet. Overdispersion is expected because team strength varies.
- The top 20 teams by matches played are all long-established teams (Sweden, England, Argentina, Brazil and so on, 850 to 1,100 matches each). I was going to compare against a 2000-onwards window.

## Modelling plan
- Features are built by replaying matches chronologically. Every feature uses only matches strictly before the match (no look-ahead), checked by a truncation test (check_no_lookahead).
- elo.py: Elo ratings with K-factor by tournament group, a home advantage that turns off when neutral, and a goal-difference multiplier. Constants are placeholders to tune.
- goals.py: attack and defence strength from time-decayed goals for and against, with shrinkage toward the global average. Version 1 has no opponent adjustment, behind the OPPONENT_ADJUSTED flag.
- shootouts.py: shrunken shootout win rate and log5
